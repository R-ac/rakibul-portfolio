# Md. Rakibul Islam — Interactive Futuristic Portfolio

A modern, highly interactive, and visually impressive personal portfolio website for **Md. Rakibul Islam**, Computer Science and Engineering student at the **Islamic University of Technology (IUT)**.

Built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, themed in an obsidian dark developer / cyberpunk aesthetic with electric cyan and emerald accents (no purple).

---

## ⚡ Key Highlights & Features

- **Cyberpunk HUD / Developer Aesthetic**: Charcoal dark theme, glowing borders, and glassmorphism.
- **2-Stage Custom Mouse Tracker**: Smooth primary glowing cursor + lagging responsive ring with hover magnetics (auto-disabled on touch & mobile).
- **Interactive Background**: Connected constellation particles with physics responding to cursor movement.
- **Interactive Developer Console / Terminal**: Live CLI emulator with commands (`whoami`, `interests`, `status`, `skills`, `projects`, `education`, `contact`, `clear`) and quick clickable pills.
- **Academic Timeline**: Animated vertical record showcasing IUT (BSc in CSE), Government Laboratory College (HSC GPA 5.00), and Nasirabad Government High School (SSC GPA 5.00).
- **Skills Matrix**: Interactive cards for C, C++, Java, Python, NumPy, and PyTorch with telemetry hover inspection.
- **Featured Projects & Modals**:
  1. *Parkinson's Disease Detection* (Ongoing Research on DaT SPECT Scans)
  2. *Striatum Isolator* (Brain ROI Anatomical Segmentation Algorithm)
  3. *Flow* (Flood Rescue Simulator Game)
  4. *Alphen* (Interactive Gym Planner App)
  5. *Gowther* (Split-Screen Multiplayer Card Game)
  6. *LED English Letter Generator* (Digital Logic Hardware Project)
- **Direct CV Download**: Configured with `/public/Md_Rakibul_Islam_CV.pdf` for one-click downloading + interactive resume preview modal.
- **Hobbies Showcase**: Interactive animated cards for Rooftop Gardening and Book Reading.
- **Central Data Management**: Easily update everything in `src/data/portfolioData.ts`.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/R-ac/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run the local development server
npm run dev
```

### Production Build
```bash
npm run build
```

---

## 🌐 Deploy to GitHub Pages / Vercel / Netlify

### Deploying to GitHub Pages:
1. Ensure the repo is pushed to your GitHub account (`R-ac`).
2. Run `npm run build`.
3. In GitHub repo settings -> **Pages** -> Deploy from `gh-pages` branch or configure GitHub Actions.
